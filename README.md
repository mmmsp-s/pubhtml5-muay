# ชั้นนิยาย Muay

รวมรายการนิยายจาก pubhtml5 สองบัญชี ([aswhk](https://pubhtml5.com/homepage/aswhk/) และ [fqeu](https://pubhtml5.com/homepage/fqeu/)) ไว้ในหน้าเดียว ค้นหาได้ ไม่ต้องเลื่อนหา

- `scraper/scrape.py` ดึงรายการ แล้วเก็บไว้ที่ `site/books.json`
- `site/index.html` หน้าเว็บที่แสดงรายการ
- GitHub Actions รันทุกวัน แล้วอัปขึ้น GitHub Pages ให้เอง กดรันเองได้ที่แท็บ Actions
